# 内置模板库索引（template library index）

> 加载技能时**只读本文件**，用于向用户展示可选模板菜单。
> 用户选定某套后，再读取对应的 `references/template-library/<id>.md` 获取该套的完整规范与风格锚定 Prompt（保持上下文轻量）。
> 新增模板时：在 `references/template-library/<id>.md` 写规范并在下表加一行。仅可发布原创或已获再分发授权的视觉资产；第三方参考图应由拥有使用权的用户在当前会话临时提供，不进入仓库。

## 可选模板一览

| 编号 | id | 面向用户名称 | 一句话风格 | 适用内容 | 含真人 | 含他人署名 | 页面结构 | 默认 |
|:--:|----|------------|-----------|---------|:----:|:--------:|---------|:--:|
| ① | `original-neutral-tutorial` | 原创中性教程风 | 浅暖灰+深灰+蓝绿色强调，原创信息设计 | AI/工具教程、技术干货 | 否 | 否 | 封面1+内容页1-6+结尾(可选) | ★ |
| ② | `ai-tutorial` | 遗留 AI 教程参考 | 米黄+黑橙标题+红框截图；仅构图与层级参考 | 仅用户确认拥有必要使用权并提供参考图时 | 是 | 是 | 封面1+内容页2-5+结尾(可选) | |

★ = 用户只发文案、未选模板时使用的默认套。

## 选择菜单话术（Step 0 / Step 1 用）

```
✅ 技能已加载（图像风格迁移 v2.4）。内置模板库现有两套风格：
① 原创中性教程风 —— 默认，无真人、无第三方署名
② 遗留 AI 教程参考 —— 仅在确认有必要使用权并上传参考图后选择

你可以：
A. 从库里挑一套 → 回复编号（如"用①"）
B. 上传你自己的风格参考图 → 我按你的图建模板
C. 直接发文案 → 默认用 ①（原创中性教程风）
```

## 字段说明

- **id**：稳定的 kebab-case 标识，决定 `<id>.md` 的命名，确立后不要改
- **含真人 / 含他人署名**：决定该套是否触发 SKILL.md 注意事项12 的"人脸不复刻 / 署名强制替换"。每套独立标注——不是所有模板都含真人/他人署名
- **页面结构**：该套参考图覆盖的页面角色（封面/内容页/结尾页各几张）
- **默认**：全库有且仅有一套标 ★
