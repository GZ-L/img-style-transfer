# 模板元信息：遗留 AI 教程参考（id: ai-tutorial）

> 本仓库不分发该模板曾使用的第三方参考图。只有用户明确选择、确认拥有必要使用权，并在当前会话提供参考图时，才可读取这份元信息并提取抽象的构图与信息层级。不得自动选择、不得作为默认模板、不得将参考图直接转交给生图工具。

## 风险元信息

- 面向用户名称：遗留 AI 教程参考
- 适用内容：仅用户确认拥有必要使用权时的 AI/工具教程、测评、技术干货
- 含真人：是；必须触发“人脸不复刻”规则。
- 含他人署名：是；必须替换账号、品牌和署名。
- 页面结构：封面 1 + 内容页 2–5 + 结尾页可选。
- 是否为全库默认：否。

## 使用边界

1. 要求用户确认其对当前提供的参考图拥有必要的使用权；无法确认时，改用 `original-neutral-tutorial` 或要求原创参考图。
2. 只提取色彩关系、信息密度、留白、层级与通用构图；不得复制人脸、原文、商标、账号、真实界面、精确插画或精确页面构图。
3. 封面使用用户照片、原创插画人物或无人物方案；未提供自有署名时返回 `needs_input`。
4. 不保存、不发布、不提交用户提供的参考图；它们仅在当前生成任务中使用。
