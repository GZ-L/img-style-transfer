# 模板规范：原创中性教程风 (id: original-neutral-tutorial)

## 模板元信息

- 面向用户名称：原创中性教程风
- 适用内容：AI/工具教程、技术干货、流程说明
- 含真人：否
- 含他人署名：否
- 页面结构：封面 1 + 内容页 1–6 + 结尾页可选
- 是否为全库默认：是

## 风格锚定

整体风格：原创的中性信息设计，浅暖灰背景、深灰文字、单一蓝绿色强调色；无人物、无第三方 Logo、无品牌界面复刻。

排版锁定：封面为左对齐大标题加抽象流程图形；内容页为清晰标题、两到三条短要点、用户提供的真实截图或原创示意区；底栏仅放用户自己的署名。

字体锁定：中文无衬线标题和正文，标题与正文层级清楚；保留充足留白。

绝对不要：第三方人脸、账号名、商标、原文、夸张光效、过饱和配色、虚构数据或产品界面。
