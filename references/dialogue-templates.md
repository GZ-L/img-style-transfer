# 对话流程话术模板（Step 1-7）

> 进入对应步骤时参照本文件的话术输出。核心规则见 SKILL.md。

## Step 0 - 技能加载确认（收到压缩包后）

> 解压 → 读 SKILL.md → 读 `template-library/_index.md` → 看默认模板图 → 给菜单 → **停下等用户回复，不要替用户选**。

```
✅ 技能已加载（图像风格迁移 v2.4）。当前可选：
① 原创中性教程风 —— 默认，无真人、无第三方署名
② 遗留 AI 教程参考 —— 仅在确认有必要使用权时选择

接下来你可以：
A. 从库里挑一套 → 回复编号（如"用①"）
B. 上传你自己的风格参考图 → 我按你的图建模板
C. 直接发正文文案 → 默认用 ①（原创中性教程风）
```

## Step 1 - 收集参考图 / 选模板（可跳过）

```
请选模板，或上传"风格/排版参考图"（1张或多张）。
- 参考图的作用是当画风/排版模板——我只学风格，不保留它的内容。
- 系列图（如小红书轮播）请尽量传完整一组（封面+内容页），我会分别分析各页角色。
- 不选也不传 → 我用库内默认模板（①原创中性教程风）。
（选好/传好后我会先输出模板分析请你确认，确认前不会动手生成。）
```

## Step 2 - 确认模板解读

```
【模板分析完成】
{输出模板规范摘要 + 风格锚定Prompt}
（若用户未选模板：说明"已启用库内默认模板——①原创中性教程风"，并输出对应 `references/template-library/original-neutral-tutorial.md` 中的规范摘要）

请确认以上分析是否准确，或需要调整。

✅ 模板锁定后，请发送您的"内容素材"——
可以是：文案/文章、截图、现有的海报/图文、或以上混合。
我会按此模板风格，对您的内容素材进行重新排版和画风重做。
```

## 快捷模式（合并确认）

用户单条消息同时提供参考图+文案，或直接发文案不传参考图时：
- 合并执行模板分析 + 内容研究，**一次性输出"模板规范摘要 + 内容规划"供用户做一次确认**
- 审美偏好（Step 5）和素材确认（Step 6）**仍需正常询问，不可省略**
- 确认后进入 Step 7 逐张生成

## Step 3 - 接收内容素材并研究（AI自主执行，按类型分支）

**分支A：教程/测评/资讯/含产品事实的种草（需要搜索）**
```
收到您的内容素材（⚠️ 此阶段收到的图片/文案都是待改造的内容，不是模板参考）。
我正在进行以下操作：
1. 提取内容中的核心信息（文案/数据/商品信息等——这些必须100%保留）
2. 搜索相关官方资料和最新信息
3. 搜索同主题的优质案例素材（小红书/知乎高赞内容），参考其内容组织和切入角度
4. 验证内容中的事实准确性
5. 补充必要的技术细节和有价值的背景信息

【研究结果】
- 已验证：{列出确认准确的信息}
- 已补充：{列出新增的信息及来源}
- 案例参考：{列出值得借鉴的点}
- 建议修正：{发现的问题及修正建议}（如有）
```

**分支B：观点/个人经历/情感表达（不搜索）**
```
收到您的内容素材。这类内容以您的个人观点/经历为核心，我不会做事实搜索，
将直接进行表述优化和图文规划，您的观点和立场会100%保留。
{若文中引用了可核实的事实（具体数据/事件），仅针对该事实点搜索验证并标注结果}
```

## Step 4 - 内容规划确认

```
基于{研究结果/您的原文}，我已将内容优化为小红书图文格式：

{输出内容规划，每页标注渲染文字量，超60字的页面附提醒}

请确认：
- 页数是否合适？
- 补充的信息是否需要保留？
- {如发现原文事实有误/过时}我查到这些与你原文不一致：{列出修正项+依据来源}——是否按修正版来？（不确认我就保留你的原文）
- {如有超字数页面}第X页文字量偏多（约N字），生成时可能出现错别字——拆分/精简/留白后期叠加，您选哪种？
- 有需要修改的地方吗？

确认后进入审美偏好选择。
```

## Step 5 - 审美偏好确认

```
内容规划已确认 ✅ 生成前想确认一下你的偏好：

1️⃣ 封面风格：
   A. 真人出镜 + 大标题（有真人半身照，适合个人IP）
   B. 纯排版封面（全标题+色块+图形，无真人，干净利落）
   C. 产品截图 + 标题（适合工具类/技术类教程）

2️⃣ 信息密度：
   A. 高密度干货（每页3-4要点+截图，信息量大）
   B. 中等密度（每页2-3要点+适当留白，阅读舒适）
   C. 低密度呼吸感（每页1-2核心信息+大量留白，轻松阅读）

3️⃣ 装饰程度：
   A. 极简（纯文字+截图，无多余装饰）
   B. 适度装饰（emoji点缀+少量图标+色块分区）
   C. 丰富装饰（贴纸/emoji/图形元素丰富，活泼风）

直接回复如"BBA"或选字母组合即可，也可以说"你看着办"我来定（默认B+B+A）。
```

## Step 6 - 生成素材确认

```
好的，生成前还需要确认几个素材问题：

📸 封面人物（仅当用户选了封面A时提问）：
   A. 我上传一张真人照片 → 请上传照片，我会参考此照片生成封面
   B. 不需要真人，换成插画/卡通风格人物
   C. 不需要人物，改用纯排版+产品元素

🖥️ 内容页截图（当内容规划中包含软件/产品截图时提问）：
   A. 我提供真实截图（效果最好，操作步骤类强烈建议）→ 请上传截图
   B. AI生成示意截图（仅适合氛围展示；操作步骤类会再次建议真图，且示意图中不会出现虚构的具体数据）
   C. 用文字描述+图形示意代替截图

🏷️ 底栏署名（必问，用于替换模板中的原作者署名）：
   内容页底栏显示什么？如"@你的账号名"和"品牌标识"
   （不提供则使用占位文字，发布前请自行替换）

🎨 其他素材：
   {根据内容动态判断：产品Logo？特定品牌色？}

可以直接回复组合，如"上传截图 + AI插画人物 + @小麦果汁"
也可以说"全部你来"，我尽量用AI生成替代（但操作步骤截图仍建议提供真图）。
```

**素材判断逻辑（AI自动执行）：**

| 内容规划中的需求 | AI的判断 | 是否需要问用户 |
|----------------|---------|-------------|
| 封面含真人 | 真人照片AI生成效果差且有假人感，建议用户上传 | ✅ 必须问 |
| 封面纯排版/截图 | AI可处理 | ❌ 不问 |
| 内容页含操作步骤截图 | 真实截图远优于AI示意（涉及读者照做） | ✅ 必须问，并倾向建议真图 |
| 内容页含产品实拍 | AI无法凭空生成真实产品图 | ✅ 必须问 |
| 底栏署名 | 必须替换模板原作者署名 | ✅ 必须问 |
| 产品Logo/品牌图标 | AI生成的Logo不精确 | ✅ 问一下 |
| 纯文字/排版/色块 | AI可处理 | ❌ 不问 |
| emoji/装饰图形 | AI可处理 | ❌ 不问 |

## Step 7 - 逐张生成图片（必须实际生成，逐张停下等用户）

```
开始生成，共{N}张图片，逐张输出，每张展示后我会停下等你反馈：

【第1张 - 封面】
{调用图片生成工具 → 展示图片 → 自检校准}
→ 封面已生成，配色/排版与模板一致。这版作为整组风格基准可以吗？（确认后我再做后续页）
   ← 停下等用户确认（确认门5）

【第2张 - 内容页1】（用户确认封面后才做）
{调用图片生成工具 → 展示 → 与基准比对自检}
→ 第2页与基准一致，继续下一张吗？
   ← 默认停下等用户

...逐张继续，每张展示+自检结论+停下...

【第N张 - 结尾页】
{调用图片生成工具 → 展示 → 自检}

---
全部生成完成 ✅ 以下是配套的小红书发布正文：
{完整正文文案，含话题标签}

📌 发布提醒：图片为AI生成，发布时请记得勾选小红书的"AIGC声明"（AI生成内容标注），
避免限流或违规风险。
```

**连续模式（仅用户明确同意时）：** 用户说"剩下的一次生成完/不用逐张确认" → 封面（确认门5）仍单独确认，确认后可连续生成后续页，但每张仍要展示+附自检结论，不静默。

**⚠️ 关键提醒：**
- 必须调用图片生成工具实际产出图片，不能只写 prompt 文字就结束
- 如果当前AI不具备图片生成能力，必须明确告知用户，并输出每张图完整的、可直接复制的 prompt
- 每生成一张就展示一张，不要等全部生成完再一起展示
- 同一张图重试不超过2次，超出后停下向用户说明并请用户决策
