# 模型适配建议 + 常见问题FAQ

> 按需读取。全文统一使用"图片生成工具"指代当前AI自带的生图能力，不绑定具体产品名（生图后端会随版本更迭，旧称呼可能失效）。

## 模型适配建议

本流程主要面向自带图片生成能力的对话式AI（如ChatGPT），也可用于其他模型：

| 模型/工具 | 适配要点 |
|------|----------|
| **ChatGPT内置图片生成（主要目标）** | 中文渲染能力强，直接写中文文案进prompt；支持传入参考图，务必附带；输出尺寸为固定档位（竖版约2:3），按SKILL.md Step 4.1b执行比例兜底；**不支持seed**，跨图一致性完全依赖"参考图直传+风格锚定" |
| Midjourney | 用`--sref`传递风格参考图URL，`--ar 3:4`设比例（支持精确3:4），风格描述放prompt开头；支持`--seed` |
| 通义万相 / Seedream | 支持参考图直传，prompt用中文效果更好，负面提示词放`negative_prompt`字段 |
| Flux | 自然语言prompt，通过ControlNet/IPAdapter传递风格参考；支持seed |
| Stable Diffusion | 权重语法`(keyword:1.2)`，ControlNet控排版，LoRA控画风；支持seed |

对于不支持参考图直传的模型，将风格锚定Prompt作为最详细的文字替代方案嵌入。

## 常见问题FAQ

**Q：AI只输出文字不生成图片？**
A：直接说"请按照规划开始逐张生成图片"。如果还是不生成，发送"请调用你的图片生成工具为我生成第1张图片"。

**Q：AI把我的内容图当成了模板？**
A：明确说"这不是参考图，这是我需要你按模板重新排版的内容素材"。

**Q：想修改某一张已生成的图？**
A：说"第X张重新生成，把{XXX}改成{YYY}"。注意：如果改的是颜色/字体/排版这类风格层面的东西，AI会先问你"全系列都改还是只改这张"——这是为了防止改完一张后整组图风格脱节。

**Q：生成的中文文字乱码/缺字？**
A：单图文字越多越容易出错。先说"第X张的文字有错，请重新生成"；反复出错时，把该页文字精简到60字以内，或改用"关键文字渲染+正文留白后期叠加"方案（发布前用美图/醒图等工具叠加文字，100%准确）。

**Q：生成的图太AI味/不像真人做的？**
A：说"去AI感不够，请参考SKILL.md Step 4.2b的去AI感要求重新生成"。或更具体："颜色太鲜艳了，降低饱和度"/"太对称了，加点不对称"。

**Q：生成的比例不是3:4？**
A：多数生图工具只支持固定尺寸档位（竖版常为2:3），无法输出严格3:4，这是工具限制不是流程错误。发小红书时2:3会被轻微裁切上下边缘——AI在构图时已避开上下5%的危险区。需要严格3:4时，让AI"用代码把这张图裁切/扩展为3:4"。

**Q：想跳过某些页面（如不要封面/结尾）？**
A：直接说"不需要封面"/"不要结尾页"，AI会跳过该页，从需要的页面开始编号。

**Q：上下文太长，AI忘了模板设定？**
A：发"请重新确认当前模板规范和风格锚定Prompt"让AI回顾。如果仍然不对，开新对话重新上传技能包，并把之前确认过的风格锚定Prompt一并粘贴，可快速恢复进度。

**Q：只想出文案不想出图？**
A：说"只输出文案和图片规划，不需要生成图片"，AI会跳过Phase 4。

**Q：某张图被安全审核拒绝了？**
A：AI会调整prompt去掉敏感元素后重试（最多2次）；仍被拒会告知你具体原因，该张建议换其他工具生成。AI不会尝试用话术绕过安全审核。

**Q：选了遗留参考模板，生成的图里出现了第三方署名或参考图人脸？**
A：这是署名/肖像泄漏。停止后续生成，确认使用权，并改用用户资产或原创中性教程风重新生成该张。
